# Rapid Service — sitio web

Sitio web informativo responsive para servicios técnicos a domicilio de línea blanca.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: diseño, colores y adaptación a móviles.
- `script.js`: menú móvil y año automático.

## Cómo verlo
1. Descomprime la carpeta.
2. Abre `index.html` con Chrome, o abre la carpeta en Visual Studio Code.
3. Para publicarlo, puedes importar el proyecto a Vercel desde un repositorio GitHub o subirlo con una herramienta compatible.

## Antes de publicar
- Confirma que los teléfonos estén escritos correctamente.
- Confirma el país/código de WhatsApp y la zona donde se presta el servicio.
- Sustituye textos generales por datos reales: horarios, cobertura, garantías y marcas atendidas.
- No se anuncian certificaciones ni garantías específicas porque no se han confirmado.
